# WuBuOS Building & Testing

> 2026-08-04. How to build, test, and ship WuBuOS. Facts verified against the
> Makefile and the repo on this date. The build is a single hosted binary that
> runs on Linux (the "Inferno emu" pattern: the kernel runs in-process).

## Dependencies

C11 toolchain (GCC/Clang), `make`. Optional: `nvcc` (CUDA paths), Vulkan SDK
(bear RL), `python3` (manifest codegen + viz). The `src/runtime/container/
wubucontainer` tree is a git submodule — initialize with
`git submodule update --init --recursive` after cloning.

## Build

```bash
make all                 # the full build (below)
make hosted              # just the hosted binary: ./src/hosted/wubu
make kernel              # kernel objects
make jit compiler runtime tools gui bridge apps worldsim metal audio shell bear
make test                # run the test gate
```

`make all` builds: `kernel jit compiler runtime tools gui bridge apps worldsim
metal audio shell bear hosted_objs`. Output: the hosted binary
(`src/hosted/wubu`), the kernel image, and the firmware blob `wubufw.fd`.

## Ship it

| Script | What it does |
|---|---|
| `build_iso.sh` | builds the bootable ISO (kernel + limine) |
| `create-usb.sh` | writes the ISO to a USB stick |
| `qemu-test.sh` | boots the image under QEMU for verification |
| `build-macos.sh` | the macOS (AVF) leg |

## Test

```bash
make test                # all 138 test targets
make test_dos_emu        # 16-bit DOS emulator (22 regression tests)
make test_dos_emu_smoke  # minimal DOS .COM run
make test_manifest       # unified syscall manifest (15 checks)
make test_vsl            # VSL syscalls (87 checks)
make test_agi_metal      # the measured-boot/AGI gate
```

Test targets are named `test_<subsystem>` — see `make help` / the Makefile.
