# WuBuOS Sitrep — 2026-11-17

Read this first if you are new to the tree. Everything here was read off the

## The one-paragraph answer

WuBuOS is the **body** of a three-repo AGI system: an OS that boots on real metal
through UEFI firmware it builds itself, runs a ZealOS-derived kernel, then hosts
a desktop plus Linux/Windows/macOS compatibility layers — with **wubuwizard**
(brain) and **WuBuNOS** (compiler) inside as submodules. It is not a Linux
distribution; it is a small OS that *contains* other OSes.

Three repos, one system:

| repo | role | what it is |
|---|---|---|
| **WuBuOS** (`/home/wubu/wubuos`) | the body | kernel, firmware, GUI, runtime, drivers |
| **wubuwizard** (`~/opt/wubuwizard`, submodule `src/brain`) | the brain | inference, training, KV cache |
| **WuBuNOS** (`/home/wubu/wubunos`, symlinked at `src/compiler`) | the compiler | HolyC frontend + ISA backends |

Separate kernel-pieces repo: **WuBuKernel** (`/home/wubu/WuBuKernel`, submodule
`src/kernel/WuBuKernel`), consumed by WuBuOS.

## The chain, end to end

1. **WuBuFW** (`src/firmware`, 57 files) — C11 UEFI firmware: PCI/ACPI/AHCI/NVMe/
   XHCI/GOP, TPM 2.0, SHA-256/RSA, Secure Boot; measures the kernel into PCR4 and
   attests before handoff. Gate: `make test_agi_metal`.
2. **Kernel** (`src/kernel`, 936 files) — ring-0, VBE framebuffer, FAT32/TXFS,
   AHCI/NVMe/PS2, interrupts, recovery/rollback. Boot tick is independent: LAPIC
   timer on vector 240 via `wubu_clock_use_apic()`, PIT fallback; APIC code is
   `#ifdef MYSEED_METAL`.
3. **WuBuKernel** submodule (`d92b0f2`) — driver model, console/arena core
   (`wubukcore`), physical memory manager (`wubukernel_pmm`) with its own
   contract gate. Bridge gate: `make test_kernel_bridge`.
4. **Runtime** (`src/runtime`, 602 files) — VSL syscall dispatch (Linux/NT/macOS),
   OCI containers via bwrap, 9P `/n` namespace, capability authority, pacman/AUR
   packaging, AT-SPI/D-Bus a11y, and the slerm'd `wubu_posix` (proven
   `-ffreestanding -nostdinc`) with **WuBuTIME** built entirely on it.
5. **GUI** (`src/gui`, 242 files) — Win98/XP shell: WM, desktop, start menu,
   explorer, terminal, taskbar, OOBE greeter, overlays. All layout comes from one
   metric owner: `include/wubu_gui_metrics.h` — unit 4; gaps 4/8/12/16; margins
   4/8/16/24; row 24; control 32; touch 40; caption 32; taskbar 48; border 2;
   radius control 4 / window 8. `src/gui/wubu_tokens.h` aliases it; the gate
   asserts agreement between defines, struct, tokens and wm.
6. **Guests** — `src/brain` → wubuwizard; `src/compiler` → WuBuNOS (16 ISA
   backends); plus `apps`/`lua`/`audio` submodules.
7. **Extras with their own gates** — `wubu_buddy` (live SDF metaball orb, emotion
   state machine linked to sensors, spawned by the hosted desktop), bear RL
   drivers, `src/spells` (vkd3d D3D12→Vulkan, swarm aggregation).
